# @m4ss/pi-skills

Open-source Pi skills for our own way of working with Pi.

## Skills

- [`commit`](skills/commit/) — Creates safe, atomic Git commits with deliberate staging, focused verification, and clear English Conventional Commit messages.
- [`repo-maintenance`](skills/repo-maintenance/) — Maintains a repository's dependencies and CI: Rust (Cargo) and Node.js (pnpm) upgrades reviewed against changelogs and release diffs, MSRV handling, security advisories, and GitHub Actions and Forgejo Actions audits.

## Install

```bash
pi install npm:@m4ss/pi-skills
```
